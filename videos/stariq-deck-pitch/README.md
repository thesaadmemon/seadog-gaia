# StarIQ — narrated investor deck (HyperFrames)

A 3:31 narrated video of the 12-slide StarIQ investor deck: one idea per slide, same narrator and
visual family as `../stariq-orbital-pitch`.

| Path | What it is |
| --- | --- |
| `index.html` | Generated by `tools/build_index.py` from `tools/index.template.html` and the narration timing |
| `compositions/d01…d13-*.html` | One sub-composition per slide (title, 11 deck slides, close) |
| `assets/img/` | Photos and marks taken from the deck |
| `assets/broll/` | Constellation and closing clips cut from the orbital pitch's 3D b-roll |
| `assets/audio/` | Narration (`vo/` + `timing.json`), score, SFX |
| `tools/` | `narration.json`, `tts.py`, `phrases.py`, `score.py`, `build_index.py` |
| `renders/stariq-deck-pitch.mp4` | The rendered video |

## Rebuild

```bash
python tools/tts.py tools/narration.json assets/audio/vo_raw af_heart 1.05 3.5
for f in assets/audio/vo_raw/n*.wav; do
  ffmpeg -y -i "$f" -af "highpass=f=75,equalizer=f=220:t=q:w=1.2:g=-1.5,equalizer=f=3800:t=q:w=1.0:g=2.5,acompressor=threshold=-21dB:ratio=2.8:attack=6:release=90:makeup=2,loudnorm=I=-16:TP=-1.5:LRA=7,aresample=48000" \
    -ar 48000 -ac 1 "assets/audio/vo/$(basename "$f")"
done
cp assets/audio/vo_raw/timing.json assets/audio/vo/
python tools/phrases.py assets/audio/vo/timing.json assets/audio/vo tools/cues.json assets/js/cues.js
python tools/score.py assets/audio/score.wav 210.7
python tools/build_index.py          # then re-run the voice-over carve on the score
npx hyperframes render --output renders/stariq-deck-pitch.mp4
```

Slide timings live in `tools/build_index.py` (`SLIDES`) and in each composition's `T0`/`DUR`.
